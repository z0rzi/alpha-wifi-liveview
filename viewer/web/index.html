Connect your camera

The live view starts by itself as soon as the camera is reachable.

  1. Turn on PC Remote over Wi-Fi MENU → Network → PC Remote Function → PC Remote: On, then PC Remote Cnct Method: Wi-Fi Access Point
  2. Put the camera on the same Wi-Fi as this computer MENU → Network → Wi-Fi Settings → Access Point Set. → pick your network and enter its password (once).
  3. Pair with this app (first time only) MENU → Network → PC Remote Function → Pairing. When the camera asks to connect to “Alpha Live View”, press OK.
Starting…

Already set up? Just switch the camera on with PC Remote on. Face/Eye AF is off in PC Remote mode; this app tracks faces itself and moves the camera’s focus point.
